# @gauzy/plugin-ai-provider-grok

Ever Gauzy AI Chat provider plugin: registers **Grok** models with the
`@gauzy/plugin-ai-chat` provider registry via `@ai-sdk/xai`.

## Configuration

| Env var | Purpose |
|---|---|
| `XAI_API_KEY` | Server-wide API key (tenants can instead set a BYOK key in Settings -> AI) |
| `XAI_BASE_URL` | Optional custom base URL |

Get an API key: https://console.x.ai
